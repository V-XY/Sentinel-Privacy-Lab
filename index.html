How Sentinel Works

Understanding the protection mechanism

1. Real-time Detection

As you type, Sentinel scans for PII patterns (emails, cards, API keys, SSNs) using regular expressions.

  • Email detection: user@domain.com
  • Credit card: 4111-1111-1111-1111
  • API keys: sk_live_..., ghp_...
  • SSN: 123-45-6789

2. Client-side Encryption

When PII is detected, it's immediately encrypted using Web Crypto API (AES-GCM 256-bit).

  • Encryption happens in your browser
  • Server never sees raw PII
  • Visual masking on blur
  • Original data stored securely

3. Secure Transmission

Only encrypted tokens are sent to the server. Original PII never leaves your device.

  • Zero-trust architecture
  • Prevents man-in-the-middle attacks
  • Compliant with privacy regulations
  • Reduces data breach impact
